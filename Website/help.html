How do I install VYBE?

Open the Download page or any Download VYBE button on this site, download the latest APK, then open it. Android may ask you to allow installation from the browser or file manager you used.

Which APK should I choose?

For most modern Android phones, choose ARM64 / arm64-v8a. This website automatically prefers that APK when it is available in the latest release.

What Android version is required?

VYBE supports Android 8.0 (API 26) and newer according to the project documentation.

Do I need a YouTube Music account?

No. VYBE can be used without signing in for core discovery and listening. Connecting an account adds playlists, liked music, listening history and more personalized discovery.

Can VYBE play local music already on my phone?

Yes. The library can include songs, albums, artists, playlists, folders and downloaded music, including supported audio already stored on the device.

Can I listen offline?

Supported tracks can be downloaded for offline playback, with progress shown in the app and Android notification area.

Does background playback work?

Yes. VYBE uses Android media playback controls and supports background playback, queue management, shuffle, repeat and crossfade.

How do synchronized lyrics work?

When synchronized lyrics are available, VYBE can load them automatically and follow the current lyric line from the player.

Which AI features are optional?

With a configured AI provider and your own API key, VYBE can help edit, translate or romanize lyrics and can generate a Daily Mix. These integrations are optional.

How do I report a bug?

Open a GitHub issue and include the VYBE version, Android version, device model and clear reproduction steps.
