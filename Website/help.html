How do I install VYBE?

Open the Download page, download the latest APK, then open the file. Android may ask you to allow installation from the browser or file manager you used. Approve that permission only for the source you trust and continue the install.

Which APK should I choose?

For most modern Android phones, choose the ARM64 / arm64-v8a build. The download page automatically prefers that APK when it is available in the latest release.

What Android version is required?

VYBE supports Android 8.0 (API 26) and newer according to the project documentation.

Do I need a YouTube Music account?

No. VYBE can be used without signing in for discovery and core listening. Connecting YouTube Music adds playlists, liked music, listening history and more personalized discovery.

Does VYBE support Spotify playlists?

VYBE can import public Spotify playlists from a playlist URL without requiring a Spotify account, and can optionally sync imported playlists with a connected YouTube Music account.

Can VYBE play local music already on my phone?

Yes. The library includes songs, albums, artists, playlists, folders and downloaded music, including supported audio already stored on the device.

Can I listen offline?

Supported tracks can be downloaded for offline playback. VYBE also shows download progress in the app and in Android's notification area.

Does background playback work?

Yes. VYBE uses Android media playback controls and supports background playback, queue management, shuffle, repeat and crossfade.

How do synchronized lyrics work?

When synchronized lyrics are available, VYBE can load them automatically and follow the current lyric line from the player.

Which AI features are optional?

With a configured AI provider and your own API key, VYBE can help edit, translate or romanize lyrics and can generate a Daily Mix. Those integrations are optional.

What should I include in a bug report?

Include the app version, Android version, device model, clear reproduction steps and any other information that makes the problem repeatable. The project's GitHub Issues page is the intended place for focused bug reports and feature requests.

How do I check for updates?

VYBE supports in-app update checks backed by GitHub Releases. You can also visit this site's Download page; it checks the latest release whenever it loads.
