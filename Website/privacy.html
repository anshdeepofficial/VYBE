Privacy Policy

This policy explains the data practices of the VYBE website and provides a high-level description of optional data flows in the VYBE Android app.

Last updated: August 29, 2026

Download VYBE

1. Website data

The VYBE website does not currently include advertising or third-party analytics scripts. It stores your light/dark theme preference in your browser's local storage so the selected appearance can be remembered.

2. GitHub release information

To show the newest VYBE version and download link, the website requests public release metadata from the GitHub API. When you download the app, the file is served from GitHub Releases. GitHub may process network and request data under its own privacy terms.

3. Hosting logs

This site is hosted on Vercel. As with normal web hosting, the hosting provider may process basic request, security and diagnostic information needed to deliver and protect the site. Those practices are governed by the hosting provider's policies.

4. VYBE app permissions and optional connections

The Android app may request access needed for features you choose to use, such as reading supported media on your device, saving downloads, or connecting optional external services. YouTube Music account connection and AI-provider features are optional. When you use a third-party service, that provider's own privacy terms also apply.

5. Credentials and account information

Do not send passwords, API keys or other secrets through public GitHub issues. Configure optional credentials only through the app's intended settings and review the relevant third-party provider's terms before connecting an account or API key.

6. Children

The website is a general software project page and is not specifically directed at children. Users should follow the age and account requirements of Android and any third-party service they choose to connect.

7. Changes to this policy

This policy may be updated as the website or app changes. The updated date at the top of this page will be revised when material changes are published.

8. Contact

For privacy questions about this project, use the official GitHub Issues page without posting private credentials or sensitive personal information.
