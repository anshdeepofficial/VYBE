About VYBE

A focused Android music experience built around choice.

VYBE combines discovery, local playback, downloads, lyrics and personalization in a modern Jetpack Compose interface that follows Material 3 principles.

Download VYBEView source on GitHub
Platform roadmap

Android today. iPhone coming soon.

VYBE is currently available for supported Android devices. An iPhone version is planned for a future release; timing and availability may change as development progresses.

What it is

Music online and on-device.

VYBE is designed to let people discover music, manage a personal library, play local audio, use supported offline downloads, follow synchronized lyrics and personalize playback without forcing every feature into one workflow.

Technology

Native Android, Material 3.

The project uses Kotlin, Jetpack Compose, Material 3 and AndroidX Media3. Its visual system supports light, dark, system and dynamic color experiences.

Compatibility

Android 8.0 and newer.

The published project documentation lists Android 8.0 (API 26) as the minimum supported Android version.

Open project

Source and releases on GitHub.

Source code, release history, issue tracking and the project license are available from the official VYBE GitHub repository.
